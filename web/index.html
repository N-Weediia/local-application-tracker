隐私与开源边界

  • 简历文本和邮箱凭据不会写入 Git 仓库；默认只保存技能摘要、投递状态和邮箱标题摘要。
  • Gmail、Outlook/Microsoft 365、QQ、163 和阿里云企业邮箱使用 IMAP 预设；若服务商要求 OAuth，请使用应用专用密码或后续 OAuth 适配器。
  • 发布 GitHub 前请删除真实简历、真实邮件、附件、授权码、OAuth token 和内部招聘链接。
